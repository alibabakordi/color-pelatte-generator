# Color Palette Generator

Simple tool to generate 5 unique colors for web design.

## Features
- Generate with button + Space key
- Lock colors you like
- Click HEX to copy
- Light / Dark / All filter
- Responsive for mobile

## Built With
HTML, CSS, Vanilla JS

## Run
Open index.html in browser
